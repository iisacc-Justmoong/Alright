## 핵심 결정

- 첫 제품은 macOS Finder 확장이다. 파일 생성, 경로 복사, 목적지 지정 복사·이동을 중심으로 한다.
- Finder Sync의 적합성·노출 범위·권한 전달을 먼저 실증한다. 모든 폴더에서의 동작을 미리 보장하지 않는다.
- C++23 핵심 로직과 Objective-C++/AppKit/Finder Sync 어댑터를 사용한다. Qt 의존성은 도입하지 않는다.
- 계정과 서버 없이 기본 파일 작업이 동작한다. 유료 기능·가격은 검증할 사업 가설이다.
- 첫 개발 작업은 기능 확장이 아니라 **등록한 로컬 폴더의 빈 공간에서 새 TXT 파일을 실제로 생성하는 수직 구현**이다.
